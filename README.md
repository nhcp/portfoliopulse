# PortfolioPulse

A crypto trading journal built with the MERN stack.

## Features
- JWT authentication (register/login)
- Log buy and sell trades
- Auto-calculate P&L per trade
- Dashboard with stats: Total P&L, Win Rate, Best Trade
- Delete trades
- Data stored in MongoDB

## Tech Stack
- MongoDB
- Express.js
- React + Vite
- Node.js
- JWT

## Run Locally

### Backend
cd backend
npm install
npm run dev

### Frontend
cd frontend
npm install
npm run dev

Open http://localhost:5173
